## 已确认的问题

- 资源下载与 Homebrew 索引需要拒绝带 `Content-Range` 的部分响应，并核对索引长度；不能仅凭成功状态码把不完整内容当成完整资源。
- Homebrew 地址保存失败时，不应让未保存的无效值污染当前设置。
- 旧版 FTP 密码清理绕过正常设置的原子保存，可能在写入失败时损坏原设置。现在先验证，再通过临时文件替换；替换失败保留原文件并提示，后续成功读取清除旧提示。无效设置在修改前保留原始备份。
- SD 文件列表在主机或系统环境变化后仍可能显示旧目录。现在立即清理旧目录、上传清单和主机资料；文件操作绑定确认时的连接、设备与环境，执行前再次核对，即使重连同一设备也拒绝使用旧确认。
- SD 重命名曾使用地址栏当前文本拼接目标，编辑地址但未打开时可能把文件移到其他目录。现在使用选中文件的父目录。
- 已登记下载缓存损坏后，再次下载仍会反复验证同一坏文件。现在保留原文件，在新目录重新下载，成功校验后才更新下载记录；失败仍可重试。
- 手动选择 DBI 后端时，设置保存失败会逃出点击事件。现在在窗口内显示错误并保留旧路径；保存成功后才更新路径和内存设置，失败可重试。
