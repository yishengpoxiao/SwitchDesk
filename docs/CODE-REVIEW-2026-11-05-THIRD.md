## 确认并修复的问题

- **存档导出与拖出**：已选快照被另一份有效 ZIP 替换后，旧入口仍会导出替换后的内容。现在核对选中的来源与内容清单；导出保持同一读句柄直到复制完成，先写临时文件再发布。历史拖出在首次读取前锁定并核验来源，复制流也保留身份与位置。
- **FTP 上传冲突**：服务器不支持 `SIZE` 时，旧实现把已有目标当作不存在。现在回退到目录清单核对，上传临时文件之后再次检查目标冲突；不支持重命名的服务明确报错，避免退化为直接写最终名称并留下半文件。
- **公共更新目录**：部分 HTTP 响应或长度不完整但语法正常的目录会被保存为最新缓存。现在核对完整响应及实际字节数，失败尝试备用端点；两者均失败则保留已有缓存。
- **电脑游戏库**：导出清单含空组件类型时会触发数据库非空约束并中断整个扫描。现在将错误字段、标识和摘要归为无效清单，继续扫描其他文件。读取无权限的清单也不会中断整个库。
- **数据库资源释放**：数据库初始化失败时释放连接与错误消息；重复关闭安全，关闭后的数据库操作在调用原生 API 之前拒绝。依据核对了 [SQLite 打开连接](https://sqlite.org/c3ref/open.html)与[关闭连接](https://sqlite.org/c3ref/close.html)的生命周期约定。
- **保护文件写入失败**：取消或写入失败后，清理本次创建的不完整文件，避免遗留临时文件阻塞重试；同名已有文件保持不变。迁移准入状态不因此改变。
