# 资源下载、Homebrew 与金手指

侧栏“资源下载”汇总公开网站文章、你配置的游戏来源、Homebrew 索引，以及手动添加的资源。下载文件先保存在电脑，随后由你选择并确认安装；搜索或下载不会自动向 Switch 写入内容。

## 从网站查找资源

1. 选择 Gamer520 或 NS 头号玩家，输入游戏或工具名称，选择类型并点“搜索资源”。
2. 选择公开文章后，点“查看原站”在浏览器检查原始说明和资源入口。文章标题、下载次数或文件名都不能证明游戏身份、地区或与当前主机兼容。
3. 网盘分享页、提取码、登录、浏览器验证以及需要解压的分发包仍在原站处理。取得实际文件直链后，可“从直链添加”；已经下载到电脑的游戏包仍可使用原有“安装游戏”入口。

Gamer520 的应用内搜索只展示页面上明确归入 Switch 游戏或金手指分类的文章，不把 PC／模拟器整合包当作 Switch 安装包。当前适配的是公开文章列表，没有把文章网页或网盘分享页解析成可安装文件。HTTP 403、登录／验证、跳转或读取失败会显示相应状态并提示打开原站，不记为搜索成功。

NS 头号玩家的旧 `.com` 入口已成为公告页。当前实现读取官方公告确认新域名，处理有限重定向，并按新站公开的匿名会话流程搜索 Switch 游戏；公告地址变化后重新搜索会更新入口。主入口不可用时会尝试公告中的备用入口。金手指与 Homebrew 暂通过带关键词的浏览器站内搜索查看，不将首页最新文章当成关键词命中。

Gamer520 的部分搜索响应会先设置匿名 Cookie，并要求重载同一地址。应用只对这一明确的初始化响应重载一次；其他访问限制、验证码或第二次失败会提示在浏览器处理，不无限重试。浏览器“站内搜索”和“搜索公开索引”均保留当前关键词及类别，结果为空时也可使用。

切换来源会清空上一次结果，需要重新搜索。网站搜索只检查当前请求返回的公开页面，不表示已遍历网站所有历史资源。

## 下载到电脑，再确认安装

可接受的直链文件类型为：

| 类型 | 文件 |
| --- | --- |
| 游戏 | `.nsp`、`.xci`、`.nsz`、`.xcz` |
| Homebrew / 插件 | `.nro` |
| 金手指 | `.txt` 或旧 `.cheat` 文本 |

直链应指向实际文件，地址末尾的文件扩展名须与资源文件名一致。ZIP／RAR 等压缩包、HTML 网页、网盘分享页、自动跳转与登录接口不能作为文件直链。需要跳转时，请在原站浏览器中取得最终文件地址或完成下载。

“下载所选到电脑”完成后，切到“已下载”查看文件。提供来源 SHA-256 时会核对摘要，不匹配不发布完成文件；没有来源摘要时仍记录本地摘要，但会明确提示来源未提供摘要。这不能等同于验证作者身份或资源授权。失败、取消或长度不符不会留下可安装的半成品，也不会覆盖已有同名文件。

安装前会再次检查电脑文件是否与下载记录一致：

- **游戏**进入原有安装预检清单，核对包内身份、存储空间和主机环境后，再手动开始安装。
- **Homebrew / 插件**目前仅支持直接 NRO，确认后写入 SD 卡 `/switch/` 下的对应目录。Tesla `.ovl`、sysmodule、Atmosphère 整合包以及任意系统目录覆盖不属于本轮安装范围。
- **金手指**需要明确的游戏 TitleID 与 16 位十六进制构建 ID，确认后写入对应游戏的标准 `.txt` 文件。下载到电脑不等于适用于已安装版本，也不自动开启游戏作弊。

“打开下载目录”或“打开所选位置”可以在资源管理器中查看文件。下载记录对应的文件被移动或删除时，会显示缺失状态。

文件保存在设置中的电脑游戏库目录下的 `Downloads/`。缺少金手指身份时，在“已下载”中点“补充金手指标识”，填写明确的 TitleID 与 BuildID；若文件名本身是构建 ID，也必须与填写值一致。主机未返回可自动核对的 BuildID，安装确认会要求你核对实际游戏版本。

## 统一资源索引格式

资源页可导入以下 JSON 格式。它与设置中的[自有游戏内容来源](CONTENT-SOURCES.md)使用的 `Base / Update / DLC / DataPatch` 组件索引不同：资源索引用于汇总可下载文件，安装包的真实身份仍在安装前解析。

```json
{
  "formatVersion": 1,
  "entries": [
    {
      "name": "示例游戏包",
      "kind": "Game",
      "url": "https://downloads.example.com/game.nsp",
      "fileName": "game.nsp",
      "sourceName": "我的文件目录",
      "sourcePage": "https://downloads.example.com/game-info",
      "description": "示例位置，请替换为实际文件直链"
    },
    {
      "name": "示例 Homebrew",
      "kind": "Homebrew",
      "url": "https://downloads.example.com/tool.nro",
      "fileName": "tool.nro",
      "sourceName": "作者发布页"
    },
    {
      "name": "示例金手指",
      "kind": "Cheat",
      "url": "https://downloads.example.com/0123456789abcdef.txt",
      "fileName": "0123456789abcdef.txt",
      "titleId": "0100000000000000",
      "buildId": "0123456789ABCDEF",
      "sourceName": "我的金手指目录"
    }
  ]
}
```

以上域名、TitleID、构建 ID 和资源名称均为占位示例，不代表真实游戏或可用下载。实际使用前应替换。

必填字段为 `name`、`kind`、`url`；`kind` 明确为 `Game`、`Homebrew` 或 `Cheat`。`fileName` 可省略，由 URL 最后一段提供；如显式填写，只接受单个文件名。可选字段为 `sha256`（64 位十六进制来源摘要）、`size`（正整数字节数）、`titleId`、`buildId`、`sourcePage`、`sourceName` 和 `description`。金手指缺少游戏或构建信息时，需要在安装前补齐并核对。

索引最多 4 MiB、10,000 条；单个游戏文件最多 128 GiB、NRO 最多 512 MiB、金手指文本最多 1 MiB。上限是当前下载器的预算，不是设备可安装性或兼容性承诺。索引不能包含重复字段或重复资源条目；HTTP(S) 地址中不嵌入用户名密码。

## 标准金手指文件与配套能力

新版导入把 `.txt` 和旧 `.cheat` 来源统一写成 Atmosphère 使用的：

```text
/atmosphere/contents/<TitleID>/cheats/<BuildID>.txt
```

标准 TXT 写入要求主机配套声明 **`cheats.text.v1`**。只声明旧 `cheats.write.v1` 的 NRO 不代表支持此路径，应使用与当前桌面源码匹配的新配套。原有 `.cheat` 历史文件仍可浏览和管理；启用／停用采用对应扩展名与 `.off` 之间的切换。

本轮开发与电脑夹具验证不包含真实主机安装、游戏内作弊效果、Tesla 或系统模块准入。真实主机步骤继续按用户安排执行。

格式依据：[Atmosphère 金手指官方说明](https://github.com/Atmosphere-NX/Atmosphere/blob/master/docs/features/cheats.md)。网站公开页面核对日期为 2026-11-04：[Gamer520](https://www.gamer520.com/)、[NS 头号玩家官方公告](https://nsthwj.com/)。初次验证中的 Gamer520 403 和 NSTHWJ JavaScript 公告页保留为历史失败记录；同日后续诊断确认正常 Cookie 初始化流程与官方新站入口，详见 [本轮修复记录](CNMT-FIX-2026-11-04.md)。
