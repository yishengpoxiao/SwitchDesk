## 从配套直接打开 DBI

配套空闲时按 **Y**，或在连接了新版配套的 Windows 端点击 **在主机打开 DBI**。配套在固定位置查找已安装的 DBI、检查 NRO 头，再通过加载器登记其为下一个程序。DBI 出现后按 **Y** 进入后端接收界面，再在主机选择文件和安装位置。[操作说明](DBI-INSTALL.md)

## 验证

**Windows 驱动诊断**增加了手动设备检查、单设备一键绑定、Zadig 官网和设备管理器入口。错误 28 只说明该设备缺少驱动。单键操作要求节点唯一、总线产品名精确为 `SwitchDesk PC`、硬件标识匹配、无已绑定服务且非复合设备。授权后通过同一个设备信息句柄再次核对，使用系统驱动库中的通用 WinUSB 功能驱动，并在返回后复查同一实例。具体步骤见[连接诊断与 WinUSB](INSTALL.md#连接诊断与-winusb)。
