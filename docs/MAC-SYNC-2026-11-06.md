# 2026-11-06 Mac 同步修复

现有 Mac 产品是 `SwitchDesk.Cli`。本轮将最新 Core 修复带入 Apple Silicon 和 Intel 的自包含包，保留终端功能范围，不宣称已有 Mac 图形界面或 USB 管理。

## 代码变更

- CLI 新增完整版本标识和 Ctrl+C 取消处理，网络参数严格校验；批量校验不匹配或未完成时返回失败退出码。
- 公共目录与 Homebrew 缓存使用临时文件原子替换，支持创建父目录，失败保留旧缓存。
- SQLite 原生库解析器从 `LibraryDatabase` 移到所有数据库共用的 Native 初始化入口；先使用 `Phase2State` 也能初始化 macOS / Linux SQLite。
- 本地上传路径仅转换操作系统目录分隔符，Unix 文件名中的反斜杠不会被改写成远端子目录。
- 快照自动清理与去重按本地平台路径大小写规则限定范围，防止大小写敏感卷上的手工归档被误纳入清理。导出在发布前重新核验实际复制的快照，减少对源文件共享锁语义的依赖。
- 新增可重复的 Mac 构建脚本，检查 Mach-O 架构、ZIP CRC、可执行权限和匹配来源，附带准确的 .NET 运行时许可。新增 Apple Silicon 与 Intel Mac CI 作业；本轮未推送或执行远端 CI。
