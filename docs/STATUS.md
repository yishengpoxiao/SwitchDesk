## 已有真机证据

已记录的硬件范围只有一台 **OLED / HOS 20.4.0 / Atmosphère 1.9.4 / emuMMC / USB 2.0 High Speed**，不能外推到其他型号、固件或运行模式。

- 配套 **0.2.4** 在完整应用模式下完成启动、X/B 操作、重新打开，以及设备、存储、游戏和存档清单读取。
- 同一配套在 Applet 模式下完成握手、目录浏览、配套文件重复下载及摘要核对、游戏图标读取；该模式未声明存档、安装和导出能力，存档请求被拒绝，不能解释为没有存档。
- Applet 模式的独立 SD 测试目录完成 ASCII 文件、3 MiB 二进制、嵌套及空目录往返、摘要核对、同名保护、重命名、删除和取消清理。仅处理测试内容，测试目录已清理。
- **中文文件名上传仍是未解决的实机问题**：0.2.4 的 `fs.write.open` 返回 `WriteOpen / 无法创建临时文件`；未验证当前配套是否修复。
- 31 条游戏记录中有 1 条内容信息不可读取，原因尚未确定；没有据此判断游戏损坏或执行删除、重装。

这些历史结果不证明当前 NRO 的新功能已经通过真机验收。最新一轮软件审查没有连接主机、部署 NRO、安装内容、写回存档或绑定驱动。

## 迁移与原生隐藏准入

`CompatibilityCatalog.Released` 当前为空。吸血鬼幸存者、死亡细胞、哈迪斯、哈迪斯 2、空洞骑士和丝之歌均为适配器或候选格式范围，不能作为已支持的迁移清单。每条允许发布的迁移规则必须记录 Steam BuildID、分支、两端格式版本、Switch 应用 ID 与内容数字版本、影响存档的 DLC、用户／槽位、迁移方向、完整度和证据；文件内 Version、修改时间或同名游戏均不能替代安装版本与身份核对。

每个组合至少完成 **五次双向往返**，在游戏内核对完整进度或明确声明的永久进度范围；还需覆盖错误用户／槽位／游戏、损坏数据、DLC 与分支不符、运行中游戏、时钟偏差、双方冲突和云替换。空洞骑士与丝之歌分别准入，哈迪斯 2 不沿用一代结论。未登记的位置、未知格式和多份无法区分的 Steam 安装仅允许检查与独立备份，不按最近时间选择或直接覆盖。

跨平台结果必须从完整目标快照生成，保留来源、未选槽位与覆盖前 Recovery 副本，不能修改旧快照身份绕过校验。PC 写回使用同卷原子替换，拒绝先删除目标的降级路径；不会自动修改 Steam Cloud 设置、退出游戏或循环覆盖争抢文件。主机恢复、断线／掉电、进程退出和日志空间不足必须用专用测试存档验收；一次 `fsFsCommit` 或电脑夹具通过不代表物理中断时可自动回滚。

原生 HOME 隐藏只有在**同一实际环境**验证 HOME／全部软件／分组表现、至少 **十轮隐藏与恢复**、**三次重启**、休眠、新安装与更新、受保护入口、无电脑连接时的离线恢复、异常日志及内容不变后，才允许启用。恢复只处理本工具造成的变化，并隔离其他设备与环境；不能用删除、归档、注销应用记录或电脑筛选冒充隐藏。当前仍无准入证据，功能保持关闭。

能力必须由配套显式声明。管理更新要求 `install.plan.v1`、`package.dependencies.v1` 和 `operations.status`；旧服务忽略字段不构成支持，不静默降级。安装保护所有用户存档，核对组件归属、实际版本、依赖和空间，并在完成后复读结果。具体协议和保护规则见[构建与协议说明](BUILD.md#usb-协议与写入保护)。

## 尚待验收与已知限制

- 当前配套的真实游戏安装、本体／更新／DLC 导出、重新安装及大文件闭环尚待验收；DBI 快捷切换也需真机核对，外部后端退出不表示安装成功。
- 存档恢复、跨系统写回及中断后恢复尚需专用测试存档验证。Recovery 副本不等于设备自动回滚；物理掉电、拔线和进程退出不能由电脑夹具证明安全。
- USB 音画、连续播放、管理与投屏切换尚待设备验收。SysDVR USB 模式占用主机端 USB 服务，仅关闭电脑播放器不足以恢复管理；详见[随包播放器说明](BUILD.md#随包播放器)。
- 超过 4 GiB、FAT32 边界、实际 NAS、空间不足、物理拔插与休眠，以及大规模备份的性能仍需实测。
- 设备身份存在 SD 随机身份降级路径，整卡复制可能复制该身份；跨主机隔离仍需专门验证。
- 快照已有清单大小与条目数限制，但尚无独立的总解压字节和耗时预算。安装流程也未提供自动旧内容回收或卸载。
- 应用没有带签名校验及自动回退的自身更新事务；NRO 仍需退出后手动替换。连接要求正确的 WinUSB 接口与同源配套；操作权限以设备能力声明及运行模式为准。

真机步骤继续按用户安排暂缓。新增兼容结论必须记录双端版本、环境、具体操作、实际结果与未测范围；私有存档、设备身份及原始日志不进入公开源码。
